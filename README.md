# RestoRAG

A Retrieval-Augmented Generation (RAG) system for restaurant operations information.

## Description

This project implements a RAG system designed to provide accurate, context-aware answers about a restaurant's operations, menu, policies, schedules, and other internal information. By combining information retrieval with large language models, the system can answer specific questions about restaurant details that might not be readily available in general knowledge bases.

## Features

- Restaurant operations information retrieval
- Menu item inquiries and dietary information
- Policy and procedure questions (hours, reservations, policies)
- Schedule and staffing information
- Context-aware answers based on restaurant-specific documentation
- Retrieval of specific details from restaurant documentation

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd RestoRAG
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

```bash
python main.py
```

## Configuration

Edit `config.py` to adjust model parameters, API keys, and other settings.
